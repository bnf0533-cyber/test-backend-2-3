# בניית backend - משחק מלחמה

## chose DB

מונגו די בי זה הבחירה הכי נכונה לי לפרוייקט הזה מכיוון שזה בסיסי נתונים מאוד דינמי בפעולות שלו

בפרוייקט כזה שהשדות הם דינמיות ואני אוסיף שדות ודגלים לתוך אובייקטים/מערכים אני חייב בסיס נתונים שיהיה במצב של שינוי מתמיד ולא במצב של שורות או סכמות קבועות
ככה שגם השמירת מצבי המשחק, הטריטוריות, הנצחונות, ההפסדים, והסיבובים מאוד משתנים לכן זה הכי נכון לי לבנות את זה עם מונגו די בי

## project structure

- backend
    - DAL : אחראי על שאילתות ל-DB וגם על הלוגיקה
    - db : אחראי על חיבור לדאטה בייס עצמו והרצת המפה בהתחלה בפעם הראשונה
    - routes : אחראי על החיבור בין קובץ ה DAL לבין החיבור לשרת עצמו
    - utils : פונקציות עזר

## endpoint

- POST/games : מומש במלואו

- GET/games/:id : מומש במלואו

- POST/ games/:id/reinforce : מומש במלואו

- POST/games/:id/attack : מומש במלואו

- POST/games/:id/move : מומש 90% (הסבר כאן למטה)

- POST/games/:id/end-turn : מומש 90% (הסבר כאן למטה)

## explanation of the last two endpoints

שני האנדפוינטים האחרונים מומשו במלואם חוץ מהחלק שאנחנו צריכים לקבל מהמחשב את התור שלו

לכן כדי שהשרת יקום ולא יקרוס אני מכבה את השורות האלה

הסיבה היא שהתחלתי את התור של המחשב אבל לא הספקתי לממש את כל המהלך שביקשו בהוראות (הוא ממש ממש ארוך)

## to run

1. הורדת הפרוייקט

```
git clone https://github.com/bnf0533-cyber/test-backend-2-3.git
```

2. התקנת הספריות:
   npm install

3. הרמת השרת

```
docker compose up mongo
```

4. הגדרת משתני סביבה בקובץ .env:

```
   PORT=3001
   MONGO_URI=mongodb://127.0.0.1:27017
   DB_NAME=game-war
```

5. הרצת השרת:
   npm start

6. הרצת טסטים:
   npm test
